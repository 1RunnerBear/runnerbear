# RunnerBear 10.30.0

## Proaktiv coachbrief

- Ny kanonisk `coachBrief` i bootstrap svarer på hva du gjør i dag, hvorfor og hva som kan endres videre.
- Briefen er bundet til aktiv planrevisjon, inputcursor og seks timers gyldighetsvindu. Utløpte eller feilreviderte beslutninger vises ikke som gjeldende.
- «I dag» viser én rolig ukesprioritet, neste nøkkelpunkt og planens neste vurdering.
- «Hvorfor denne økten?» sier nå eksplisitt om planen er endret, hvilke økter som berøres, ukeeffekten og når vurderingen fornyes.

## Mål som kan forstås

- Alle fire rutene under «Mot målet» kan åpnes.
- Hovedmål, 5 km-form, retning og neste gate forklares med betydning, datagrunnlag, hva som forbedrer statusen og konsekvensen for planen.
- «Krever tydelig framgang» viser gap når grunnlaget tillater det, uten falsk presisjon eller oppfordring til å jage fart.

## Sikkerhet og flyt

- Ingen endring i plan-, historikk- eller synkautoritet.
- Fullførte økter forblir uforanderlige, endringer gjelder fremover, og Tredict/Garmin beholder ti dagers idempotent projeksjon.
- Nye coach- og måldialoger følger eksisterende modal-, fokus-, Escape- og tilgjengelighetsmønster.
