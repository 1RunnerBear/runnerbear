# RunnerBear v11.5 — Premium UX Lock

RunnerBear 11.5 turns Coach Live and the app's dialog surfaces into one coherent premium experience.

## Changed

- Coach Live answers are presented as scannable advice sections instead of undifferentiated chat bubbles.
- Context, plan connection and One Decision are clearer without adding dashboard chrome.
- Welcome, loading, thinking, error and retry states are calmer and more explicit.
- The composer now grows with the message and supports Enter to send and Shift + Enter for a new line.
- Mobile Coach Live uses a stable full-height layout with safe-area handling.
- Modern sheets and the goal manager now share one dialog backdrop, surface, spacing, header and focus style.
- Active dialogs keep keyboard focus inside until dismissed.
- Two older Coach Live CSS layers are consolidated into the canonical v11.5 premium UX layer.

## Unchanged safety contract

- AI cannot write the plan.
- Plan changes still require explicit confirmation and remain undoable.
- Automatic reduction remains capped at 20 percent.
- The four-tab navigation and server-authoritative plan revision model are unchanged.
